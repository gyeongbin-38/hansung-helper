# Hansung Agent Bootstrap Kit

Drop the contents of this folder into the repository root.

Recommended first run:

1. Start a fresh planner/maintainer agent.
2. Give it `docs/agent/AUTONOMOUS_START_PROMPT.md`.
3. Let it perform recon and backlog decomposition before coding.
4. Run implementation agents Issue-by-Issue.
5. Route completed PRs to a different fresh verifier using `docs/agent/INDEPENDENT_VERIFIER.md`.
6. Use `docs/agent/IMPLEMENTER_HEARTBEAT.md` for long-running implementation heartbeats.

Canonical docs:

- `PROJECT_ARCHITECTURE.md`
- `docs/product/PRODUCT_UI_SPEC.md`
- `AGENTS.md`
