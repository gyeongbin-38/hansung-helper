# 한성 학사 도우미

한성대학교 학생의 수업 마감·시간표·학사일정·비교과·졸업요건을 한곳에서 모아 보는 **비공식** 학사 도우미입니다.

**서비스**: https://hansung-helper.gyeongbin-38.workers.dev

> 한성대학교 공식 서비스가 아닙니다. 학교 시스템에 공개되거나 로그인 뒤 볼 수 있는 화면을 읽어 정리해 보여 주며, 최종 확인은 학교 공식 시스템에서 하세요.

## 기능

- **홈 대시보드** — 졸업 진행 현황, 임박한 과제·강의 마감, 오늘 할 일을 한눈에 표시
- **수업·과제 (LMS)** — 코스모스 LMS의 수강 과목·주차별 진도·과제·퀴즈 마감을 자동 수집해 달력과 목록으로 정리
- **졸업 현황** — 종합정보시스템의 이수학점·성적·학적 정보를 수집해 전공별 졸업요건 충족 현황과 대조
- **시간표** — 전 학기 강의 카탈로그 검색, A/B/C 안 비교, 수강 계획 저장
- **비교과** — HSU 포털의 비교과 프로그램 목록·개인 포인트·마감 알림
- **학사일정** — 학교 공식 학사일정을 달력·ICS로 제공
- **AI 학사 상담** — Cloudflare Workers AI 기반 질의응답. 일일 한도 소진 시에도 오프라인 기본 안내가 계속 동작

## 작동 방식

- **계정 연결**: 학교 학번·비밀번호로 한 번 인증하면 학교 세션 쿠키만 AES-GCM으로 암호화해 단기간 보관합니다(기본 2시간, '자동 연결 유지' 선택 시 최대 3일). **비밀번호는 저장하지 않습니다.** 저장된 세션으로 비밀번호 재입력 없이 재수집합니다.
- **수집 큐**: D1 기반 전역 수집 큐가 동시 수집 수를 제한해 학교 서버에 부하를 주지 않도록 합니다. 위치 확인·쿨다운·하트비트·정체 티켓 정리를 포함합니다.
- **공개 데이터 스냅샷**: 강의 카탈로그·비교과 목록·학사일정 같은 공개 정보는 크롤러가 미리 수집해 D1 스냅샷으로 제공합니다. 사용자 요청 경로에서 학교 서버에 실시간 접속하지 않으며, 수집 이상(급감) 감지 시 이전 스냅샷을 유지합니다.
- **보조 수집 경로**: 브라우저 세션을 쓰는 크롬 확장(`extension/`)과 콘솔 붙여넣기 수집(`public/lms-collect.js`)을 백업 경로로 제공합니다.

## 프라이버시와 보안

- 학교 비밀번호는 서버·DB·로그 어디에도 저장하지 않습니다.
- 학교 세션 쿠키는 AES-GCM 암호화 + 짧은 만료 + 로그아웃·계정 삭제 시 즉시 삭제합니다.
- 계정 식별자는 HMAC 처리해 DB에 학번 원문을 두지 않습니다.
- 학교 접속은 `info/learn/hsportal.hansung.ac.kr` allowlist로 제한하고 HttpOnly 세션·Origin 검사·로그인 시도 제한을 적용합니다.
- AI 상담은 비밀번호·쿠키를 모델에 보내지 않고, 개인 학사 요약은 사용자가 선택한 경우에만 서버가 생성합니다.

## 개발 시작하기

- Node.js **22.13 이상**과 npm, Python **3.10 이상**이 필요합니다. CI는 Node 22 / Python 3.12를 사용합니다. nvm-sh(macOS/Linux) 사용자는 `nvm install` 후 `nvm use`로 `.nvmrc`를 적용할 수 있습니다.
- 저장소를 clone한 뒤 프로젝트 폴더에서 `npm ci`를 실행합니다. 기본 로컬 개발에는 Cloudflare 로그인이나 프로덕션 권한이 필요하지 않습니다.

| 작업 | 명령 | 접속 주소 / 특징 |
|---|---|---|
| 화면 개발 | `npm run dev` | 보통 http://127.0.0.1:3000, 체험 모드. 계정 저장 검증은 백엔드 모드 사용 |
| 전체 실행 | `npm run dev:backend` | 빌드 → 로컬 DB 마이그레이션 → http://127.0.0.1:8787 |
| 이미 빌드한 서버 재실행 | `npm run start` | 8787, 변경한 서버 코드는 먼저 재빌드 필요 |
| 로컬 DB 마이그레이션 | `npm run db:migrate:local` | 적용 이력 관리. 여러 번 실행해도 미적용 SQL만 실행 |
| 공통 PR 검사 | `npm run verify` | 타입 → 린트 → 단위 테스트 → SQLite 검사 → 빌드 |
| 로컬 HTTP 검사 | `npm run test:http` | 다른 터미널에 8787 서버를 켠 뒤 실행 |

로컬 DB는 **프로젝트 루트 `.wrangler/state/`**에 저장하므로 `dist`를 재빌드해도 유지됩니다. `npm run dev:backend`는 계정 API와 D1을 로컬에서 실행하지만 학교 인증·수집은 실제 학교 서버에 연결합니다. 기본 검사에는 실제 계정이 필요하지 않습니다.

## 기여와 주의

`master` 직접 push는 금지이며 `feat/`·`fix/` 브랜치 + PR(CI 통과 + 리뷰)로 진행합니다. `.env*`·`.dev.vars*`·비밀번호·쿠키·학번 원문·`lms-data.json`·생성된 DB/빌드 결과는 커밋하지 않습니다. `published-personal/`은 소유자의 별도 비공개 배포 저장소이고, 프로덕션 배포는 소유자가 진행합니다. 자세한 규칙은 [CONTRIBUTING.md](CONTRIBUTING.md)를 참고하세요.
