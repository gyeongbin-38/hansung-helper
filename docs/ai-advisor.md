# AI 학사 도우미

학사 상담과 서비스 사용 안내를 `#advisor`에서 제공합니다. 기존 규칙 안내도 별도로 사용할 수 있습니다.

- 모델: Cloudflare Workers AI `@cf/google/gemma-4-26b-a4b-it`. 추가 패키지·브라우저 API 키 없이 `AI` 바인딩을 사용합니다.
- 서버: `POST /api/advisor`. 같은 출처 JSON, 유효한 계정 세션, 최대 600자 질문과 최근 2회 대화를 받습니다. 시스템 역할 주입과 다른 계정의 컨텍스트 전달은 허용하지 않습니다.
- 기본값은 개인 학사 정보 미사용입니다. 사용자가 선택한 경우에만 서버가 현재 계정의 저장 자료에서 허용된 학사 요약을 구성합니다. 클라이언트가 보낸 프로필은 사용하지 않습니다.
- 자동 전송 범위: 학과·입학연도·계획 과목과 합산값·직접 입력값의 합계·학교 학점/포인트 요약·일주일 마감. 이름·학번·성적·개인 일정 제목·학교 쿠키·비밀번호·원문 HTML은 제외합니다. 질문에 직접 쓴 내용과 최근 답변은 모델로 전달되므로 UI에 안내합니다.
- 공개 데이터는 기존 D1 스냅샷 우선/번들 폴백으로 읽습니다. 출처 화면과 기준일은 서버에서 만들고, 모델이 임의로 생성한 링크를 실행하지 않습니다.
- 상담은 읽기 전용이며 졸업 판정·수강신청·삭제를 실행하지 않습니다. 수강 계획, 사용자 입력, 학교 수집본을 구분합니다.
- 계정당 15분에 10회, 서비스 전체 UTC 하루에 100회로 제한합니다. 기존 `academic_login_limits`에는 별도 접두사의 카운터만 기록합니다. 질문과 답변은 앱 서버·DB에 보관하지 않습니다. 실제 과금은 Cloudflare 요금제와 모델 사용량을 따릅니다.
- 답변을 반환하기 전에 세션을 다시 확인합니다. 로그아웃·화면 이탈·개인 정보 선택 변경 시 이전 대화와 진행 요청을 정리합니다. 모델 실패/제한 시 질문을 유지하고 재시도·기본 안내 전환을 제공합니다.

`GET /api/advisor`는 바인딩 유무만 알립니다. 모델 추론 성공까지 보장하는 건강 점검은 아닙니다. `HANSUNG_ENABLE_AI=0`으로 배포하면 AI를 끄고 기본 안내를 유지합니다. 로컬은 기본 비활성이며 `HANSUNG_ENABLE_AI=1`로 빌드하면 원격 AI 바인딩을 연결합니다. 로컬에서도 실제 호출은 사용량에 포함됩니다.
