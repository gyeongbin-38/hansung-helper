## 프론트 브라우저 검증 재실행

1. `npm run dev -- --hostname 127.0.0.1 --port 4339`로 체험 모드 서버를 시작한다. `--host` 대신 vinext가 지원하는 `--hostname`을 사용한다.
2. 로컬에 `puppeteer-core`와 Chrome을 준비한다. 별도 설치 경로를 쓸 때는 `FRONTEND_QA_DRIVER`에 puppeteer-core의 ESM 진입 파일을, Chrome 경로가 기본값과 다르면 `CHROME_PATH`를 지정한다.
3. `node scripts/qa-frontend.mjs`를 실행한다. 서버 주소를 바꿨다면 `FRONTEND_QA_URL`을 설정한다.
4. 결과 JSON과 화면은 gitignore된 `outputs/frontend-qa/`에서 확인한다. 이 검증은 공개 카탈로그와 별도 Chrome 체험 데이터만 사용한다.
