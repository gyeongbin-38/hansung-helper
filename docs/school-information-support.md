# 학교 정보 수집 지원 범위 (BE-02)

기준 코드: PR #58의 기반 `7e5be5b`와 이 문서의 변경분. 학교 UI와 실제
학생별 권한은 달라질 수 있으므로 다음은 **구현 범위**이며 실계정 대조를
완료했다는 뜻이 아니다. 학번·비밀번호·쿠키·개인 원본을 이 문서나 이슈에
기록하지 않는다.

| 출처와 화면 | 인증·갱신 시점 | 구현된 정보와 활용 | 부분 지원·정보가 없을 때 |
| --- | --- | --- | --- |
| 종합정보 로그인 및 메인·좌측 메뉴 | 학교 계정 인증 후 로그인/재수집 시 서버에서 수집 | 학적 요약의 이름·학과·추정 입학연도를 프로필 빈칸에 반영 | 학년·재학/휴학 상태, 트랙과 입학유형은 안정적으로 확정하지 않음. 식별자가 없으면 해당 값 미제공 |
| 종합정보 성적/이수 내역 메뉴 | 같은 학교 세션, 메뉴 라벨로 누적 성적 우선 탐색 | 파싱 가능한 과목 코드·명칭·구분·학점·학기·등급과 누적 학점/평점; 이수 내역·추천 참고 | 학교별 메뉴·비공개·미확정·재수강 원문과의 완전한 일치 미검증. 메뉴 실패 시 진단과 이전 성공본을 참고하며 빈 목록을 미이수 확정으로 취급하지 않음 |
| 종합정보 비교과 포인트 메뉴 | 같은 학교 세션, 포인트 메뉴 탐색 | 파싱 가능한 누적 포인트 총점, 졸업요건 참고 | 개인 신청·참여·수료 및 적립/취소 건별 내역은 수집하지 않음. 값이 없으면 미확인 |
| 종합정보 졸업 가사정/심사 메뉴 | 같은 학교 세션, 관련 메뉴 탐색 | 확인 가능한 항목·기준·취득·판정 원문 참고 | 메뉴가 없거나 표를 해석하지 못하면 미확인. 앱의 졸업 예측은 학교 최종 판정이 아님 |
| COSMOS 대시보드·온라인 출석부·과제/퀴즈 목록·퀴즈 상세 | 서버가 학교 계정으로 로그인 후 비동기 수집, 재인증 재수집 가능 | 첫 화면에 노출된 과목 및 파싱 가능한 출석·과제 제출·퀴즈 응시·마감; 수업 현황과 알림 | 첫 화면은 전체 등록 강좌/성적표 보장이 아님. 목록 오류는 `errors`, 개별 상태 미확인은 `uncertain`, 지연은 `lmsPending` 등으로 구분하고 이전 결과 보존. 실제 학교 원문 대조 필요 |
| COSMOS 브라우저 확장·콘솔 수집 | 같은 브라우저의 학교 로그인 세션. 확장은 앱 열기/수동/주기적 수집, 콘솔은 수동 | 학교 탭에서 수집한 과목·출석·과제·퀴즈 | 확장 계정과 앱 계정의 동일성을 증명할 수 없어 **로그인 계정 자동 가져오기는 잠정 차단**. 체험 경로만 별도 확인 가능; 실계정·다중 계정 검증 미완료 |
| 개설강의 카탈로그 | 공식 자료를 학기별로 수동 import, 요청마다 학교에 접속하지 않음 | 보유 학기 강의 분반·시간·학점; 검색·계획·시간표 | `GET /api/courses?semester=YYYY-S`에서 자료 없는 학기는 404. 개인 확정 수강이나 다음 학기 개설 보장 아님 |
| 학사일정 | 학교 공개 학사일정 스냅샷, 갱신 작업 성공 시 교체 | 공지된 일정·기간; 홈과 달력 | 개인 시험 일시·장소 아님. 갱신 실패 시 이전 스냅샷을 제공하므로 확인 시각·원문을 함께 살펴야 함 |
| 비교과 공개 모집 목록 | 학교 포털 공개 목록 스냅샷, 갱신 작업 성공 시 교체 | 모집 정보·신청 기간·공개 포인트; 활동 탐색 | 개인 신청·참여·수료 상태 아님. 오래된 자료는 현재 접수 여부를 확정하지 않고 원문 확인 필요 |
| 학과 공식 졸업요건 공개 페이지 | 학과 페이지 수집 스냅샷, 요청 경로에서 실시간 학교 조회 없음 | 수집된 안내 문구·첨부/이미지 메타데이터·일부 학번 표 | 누락·이미지·첨부·학번/전과/편입 예외는 원문 확인 필요. 검증되지 않은 졸업 가능 여부를 자동 확정하지 않음 |

로그인 실패·세션 종료·외부 시스템 지연은 사용자 데이터 없음과 구분해야 한다.
계정 API는 `docs/api-contract.md`의 private/no-store 응답을 사용한다. 일부
파서의 오류 유형은 아직 공통 진단 형식으로 표준화되지 않았다(BE-03/09).
실계정의 필드별 지원과 경계 사례는 합성 fixture만으로 완료 처리하지 않는다.
