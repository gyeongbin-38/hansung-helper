# 포털 졸업요건 수집 범위

- 졸업가사정 결과와 졸업요건은 각각 다른 메뉴 슬롯으로 찾는다. 후자는 포털 표의 셀 텍스트와 행·열 병합을 보관하며 숫자나 트랙의 의미를 임의로 판정하지 않는다. 구조 인식에 실패하면 실패로 표시하고 이전 표를 보존한다. 실제 학교 계정의 화면 구성에 대한 추가 확인이 필요하다.
- 학과와 제1·제2트랙은 별도 필드다. 누락된 라벨에서 이름이나 순서를 추측하지 않는다. 성적표에서 `선필교`는 `교필`과 구분하며 영역이 명시된 경우에만 보관한다.
- F 성적은 이수 학점에서 제외하고 확인 항목에 따로 표시한다. 동일·대체과목의 재수강 인정 여부는 판정하지 않는다. 성적이 부분 미확정일 때 F 이력은 누적 보존한다.
- 학교의 [교양교육과정 이수학점](https://www.hansung.ac.kr/hansung/6219/subview.do)은 19~23학번의 총 28학점 이상과 24학번의 31학점(13·15·3)을 구분한다. 신입학 2023과 2024 외의 입학연도·편입에는 이 참고 기준을 추론하지 않는다. 일반선택의 중복 인정과 교과목·영역별 세부 충족은 자동 판정하지 않는다.
- [2026학년도 트랙선택 안내](https://www.hansung.ac.kr/bbs/hansung/2127/221936/artclView.do)의 융합전공 I은 두 전공 각 39학점, 총 78학점, 자유선택 21학점을 안내한다. 화면에서 2023·2024 신입학의 융합전공 I 선택 시 전공 합계 기준을, 2024 신입학에 한해 자유선택 기준을 보여준다. 과목별 트랙 배분이나 중복 인정이 확인되지 않아 충족 판정은 보류한다. 21학점 자유선택을 2023학번에 자동 적용하지 않는다.
- [학사운영규정 졸업사정 기준](https://rule.hansung.ac.kr/lmxsrv/law/lawFullContent.do?SEQ=104&SEQ_HISTORY=1640)은 전체 평점평균 2.0 이상을 명시한다. 최신 성적 수집에서 평점이 확인된 경우에만 비교하며, 이전 값을 보존한 경우 확인 필요로 표시한다.
- 비교과 포인트는 학교 SSO를 흉내 내지 않는다. 공식 포털 링크와 직접 입력란을 제공하고 학교 수집값과 사용자 입력값은 구분한다.
- 학과 규정은 별도 GitHub Actions 작업에서 매일 04:30 KST에 수집한다. 전체 수집 또는 게시 검증이 실패하면 이전 스냅샷을 유지한다. 자동화는 기본 브랜치에 반영된 뒤 필요한 Cloudflare Actions 비밀값이 설정돼야 작동한다.
