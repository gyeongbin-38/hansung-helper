# 백엔드 세부 작업 패키지 — 2026-11-11

실행 목록은 **46개**다. [인계 요약](backend-mvp-followup.md)의 작업을 작은 검증 단위로 나눈 목록이며 중복 발주가 아니다. 기존 구현이 완료 조건을 만족하면 재구현 대신 공통 SHA의 코드·검증 근거를 연결해 완료 처리한다.

BE-02 지원 범위 초안은 [학교 정보 지원 목록](school-information-support.md),
BE-04 합성 응답과 익명화 지침은 [fixture 안내](../tests/fixtures/school/README.md)에
기록한다. BE-12의 출석표 대체 경로와 성적표 필수 열 누락을 추가 검증했지만,
실제 학교 응답과 전체 출처 검증이 남아 있으므로 완료로 표시하지 않는다.
BE-08은 COSMOS 상세 수집의 요청·응답 본문에 남은 시간 제한을 전달하고
미시작 과목과 부분 성공을 검증했다. 로그인 전체와 종합정보 경로, 실제 학교
네트워크 및 공통 실행 예산은 아직 검증되지 않아 완료가 아니다.

주 담당은 백엔드 `suunme`다. 프론트 연동은 `gyeongbin-38`와 맞추고, 권한·운영 비밀값·운영 DB 작업·최종 배포는 소유자가 수행한다. P0는 실사용·운영 전 확인, P1은 다음 기능 묶음, P2는 근거 데이터 확보 후 확장이다. 모든 P1/P2를 첫 배포의 병합 조건으로 묶지 않는다.
