# 확장 수집 계정 확인과 오류 보호 (BE-29/30)

확장의 `postMessage`는 같은 origin에서 만들어진 메시지도 구분할 수 없고,
확장이 보내는 학번·이름·과목 목록은 학교가 인증한 증거가 아니다. 공유
브라우저에서 COSMOS 계정과 앱 계정은 독립적으로 전환될 수 있다. 따라서
로그인 계정에 확장 수집본을 저장하는 현재 차단을 유지한다. 캐시 삭제나
새로고침만으로 학교 계정이 일치한다고 판단하지 않는다.

차단 해제 후보는 학교가 제공하는 검증 가능한 인증 경로를 통해 서버가 앱
계정과 학교 세션의 동일성을 확인하고, 해당 확인 결과를 특정 앱 세션과 짧은
유효기간 및 일회성 수집 요청에 결합하는 방식이다. 학교의 인증 방식과 실제
응답을 확인하기 전에는 구현 가능성이나 보안성을 확정할 수 없다. 다른 학교
계정, 다중 탭, 계정 전환, 로그아웃·탈퇴 후 늦은 응답, 만료·재전송과 잘못된
origin을 서버 저장 경계까지 검증하고 리뷰한 뒤에만 재개 여부를 결정한다.

브라우저 확장 수집의 실패 진단에는 허용된 고정 오류 코드만 기록한다. 학교
응답 원문과 임의 예외 문자열은 콘솔·세션 캐시·앱으로 전달하지 않는다.
현재 확장 자체는 사용자 브라우저의 COSMOS 세션을 사용하므로 위의 서버 측
계정 일치 검증을 제공하지 않는다. BE-29/30 전체가 완료된 것은 아니다.
